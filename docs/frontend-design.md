# CareerLens 前端改版

## 设计依据

采用用户要求的高 Star 前端设计技能。2026-10-19 核对 GitHub 页面：anthropics/skills 181.9k、nextlevelbuilder/ui-ux-pro-max-skill 137.1k、pbakaus/impeccable 82.6k、vercel-labs/agent-skills 32.6k。比较口径为技能来源仓库，不是单个技能的独立排名。GitHub API 当时限流，因此采用 GitHub 仓库页显示的近似数值。

实际应用技能：anthropics/skills/skills/frontend-design。按其要求先确定产品语境、设计 token 和布局，再进行实现与截图复核。

## 产品语境

大学生管理不同岗位的简历与练习记录。工作台应优先呈现真实项目、状态和下一项操作。保留文字面试、诊断证据、离线资源和原生 Web 技术；不增加新的前端依赖或修改后端合同。

## 两种布局与取舍

候选一：保留侧栏、放大主视觉、统一卡片。这仍会重复原版的通用仪表盘结构，不足以解决用户指出的模板感，放弃。

候选二：采用求职档案工作台，顶部为功能标签，正文左对齐，真实材料列表作为首页主体；右栏提供项目处理和面试提示。使用单一蓝色表达可操作内容。采用此方案。

    顶部：品牌 | 工作台 材料 诊断 面试 档案 | 引擎状态
    正文：页面标题与说明                    主要操作
          项目与训练数量的简要记录
          求职项目列表                     当前待办
          最近面试记录                     使用说明

## 视觉 token

- 纸白 #FFFFFF：文档和编辑区域。
- 冷灰 #F4F6F9：工作区背景。
- 墨蓝 #243247：主文本。
- 档案蓝 #315C9C：主要操作、当前标签和图表。
- 线灰 #DCE3EC：字段与分区边界。
- 深灰 #5F6E82：次要说明，保证可读性。
- 正文优先采用本地 Noto Sans CJK SC、Microsoft YaHei；中文页面标题使用本地中文宋体家族，表达材料与档案的文档感，不请求在线字体。
- 正文 14–15 px，字段 14 px，主标题 30–34 px；重要结果文字不使用低对比的小字号。
- 顶部标签导航，主区域最大宽 1280 px；桌面按约 2:1 分栏，窄屏改为单栏。

## 自检后的修订

初步的“编辑式排版”容易退化为米色衬线报纸模板。因此改用冷白背景和明确的蓝色交互，保留适度圆角而非一律直角，用标准列表表达真实记录。不使用大字口号、全大写眉题、装饰数字、星星图标、模拟用户头像或画出来的文档插画。数字仅表示数据库中的实际数量。

## 验证

浏览器覆盖创建、示例载入、保存、诊断、五轮面试、草稿、暂停恢复和报告；截图检查工作台、材料、分析、面试与窄屏。保留可见焦点、跳转主内容、当前导航状态、减少动态效果偏好及所有本地资源约束。运行原有后端测试。
